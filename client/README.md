# GitContext — Web Client

The official Next.js frontend for **[GitContext](../README.md)**: an intelligent, full-stack codebase companion that indexes GitHub repositories into high-dimensional vector space for semantic search and conversational AI with line-level citations.

---

## 🛠️ Frontend Stack

- **Next.js 16.4 (App Router)** with Turbopack
- **React 19.3**
- **Tailwind CSS v4**
- **Base UI (`@base-ui/react`)**
- **TanStack React Query v5**
- **Streamdown & Lucide Icons**

---

## 🚀 Getting Started

Ensure the backend server is running on `http://localhost:8080` (or configured via `NEXT_PUBLIC_API_BASE_URL`).

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

For complete project details, architecture diagrams, and full-stack setup, please refer to the root **[README.md](../README.md)**.
